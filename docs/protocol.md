## 2. 帧格式

```
+--------+--------+--------+--------+---------+--------+
| 帧头   | 类型   | 长度   | 载荷   | 校验    | 帧尾   |
| 0xAA55 | 1 byte | 1 byte | N byte | CRC8/16 | 0x5A   |
+--------+--------+--------+--------+---------+--------+
```

| 字段 | 长度 | 说明 |
| --- | --- | --- |
| 帧头 | 2 | `0xAA 0x55`，用于字节流对齐 |
| 类型 | 1 | 见第 3 节 |
| 长度 | 1 | 载荷字节数，不含头尾与校验 |
| 载荷 | N | 见第 3 节 |
| 校验 | `待定` | 覆盖范围：类型 + 长度 + 载荷 |
| 帧尾 | 1 | `0x5A` |

**字节序**：`待定`（建议统一小端，并用 `memcpy` 而非强制指针转换，避免对齐问题）。

## 3. 消息类型

| 类型码 | 名称 | 方向 | 载荷 | 说明 |
| --- | --- | --- | --- | --- |
| `0x01` | `BALL_STATE` | A → B | `待定` | 小球位置、速度 |
| `0x02` | `RAIL_CMD` | A → B | `待定` | 目标导轨角度 |
| `0x10` | `CHIP_B_STATUS` | B → A | `待定` | 心跳、故障码 |
| `0x11` | `CHIP_B_ACK` | B → A | `待定` | 指令回执 |

> 载荷字段建议用 `int16`/`float` 明确物理量与单位（mm、mm/s、0.1°），
> **把单位和缩放写进本表**，否则两边一定会对不上。

## 4. 异常处理

| 情况 | 处理方式 |
| --- | --- |
| 校验失败 | 丢弃该帧，计数 `rx_crc_err` |
| 长度非法 | 丢弃并重新搜索帧头 |
| 超时未收到对端帧 | `待定（如 100 ms 判定失联 → 进入安全状态）` |
| 失联后的动作 | A：停车；B：导轨回水平 |
