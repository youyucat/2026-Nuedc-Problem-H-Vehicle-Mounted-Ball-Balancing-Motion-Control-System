# 循迹 PC 仿真

与 `stm32f411_ball/Core/ctrl_v2/sim` 同一套思路：**被控对象是模型，控制器是真代码**。
产品侧 `app/line_task.c`、`control/`、`services/line_processing.c`、
`drivers/encoder_speed.c` 原样编译，一行不改；`sim_platform.c` 提供全部
硬件 mock（电机/编码器/灰度/时钟），`sim_track.c` 是赛道几何。

## 编译与运行

```bash
cd sim
make                    # 或直接 gcc（见 Makefile）
./sim_line              # 跑全部 4 个场景，默认参数
./sim_line 2 180 130 200   # 单场景：场景号 kp kd base
./sim_line 2 120 130 260 100 800 45   # 再加 tau_ms / vmax / 前视距离
./sim_line 1 120 130 260 100 800 60 v # 末尾加 v = 逐 200ms 打印轨迹
```

场景：1 直线起步（偏 8mm）· 2 R500 弯 · 3 R250 急弯 · 4 线中断（丢线恢复）

指标：横向偏差峰值 maxOff、误差峰值、丢线次数/累计时长、是否进 FAULT、里程。

## 模型（2026-10-25 首版，参数待实测校准）

| 项 | 值 | 依据 |
| --- | --- | --- |
| 轮距 | 140 mm | 估计 |
| 传感器前视 | 60 mm | 估计 |
| 探头间距 | 10 mm（±35mm 覆盖） | 对应 ±3500 位置图 |
| 线半宽 | 12 mm + 3mm 过渡 | 常规赛道胶带 |
| 满占空比轮速 | 800 mm/s | 估计 |
| 电机一阶滞后 | 100 ms | 估计 |
| 灰度 | 黑 500 / 白 3400 + 噪声 15 | 近似 |
| 编码器 | 1489 counts/rev、150.8mm/rev | config 实测值 |
| 控制拍 | 5 ms，编码器 10ms 采样 | 与固件一致 |

**tau 和 v_max 必须实车实测后替换**（从 PWM 阶跃到轮速稳定的响应）。

## 首轮结论（默认 kp=120 kd=130 base=260）

| 场景 | 结果 |
| --- | --- |
| 直线 | ✅ maxOff 16.9mm，零丢线 |
| R500 弯 | ⚠️ 等幅画龙，3 次丢线，maxOff 157mm |
| R250 急弯 | ⚠️ 1 次丢线 |
| 线中断 | ✅ 摇头恢复正常触发 |

**弯道画龙的对策（已验证）**：

- `base` 降到 150：**零丢线，maxOff 24mm** —— 速度是决定性因素
- 加强转弯自适应减速（`TEMPLATE_LINE_TURN_DECEL_FRACTION` 10 → 100）：
  丢线时长 1785 → 550ms，maxOff 157 → 100mm，有收益但不根治
- KP 加大反而更差（120→360 单调恶化，相位裕度问题）
- KD 130~450 与电机 tau 50~200ms 均不敏感

结论：**弯道必须减速**。实车策略：直道 base 保持 260，进弯靠打角
自适应减速（建议 FRACTION 提到 50~100 实测），或者干脆按赛道分段限速。

## 已知的模型局限

- 无侧滑/轮胎极限：实际车过弯更快就会机械甩出，仿真里只会「丢线」
- 电池电压恒定、无打滑
- 灰度模型理想化（无光照渐变、无串扰）
- 电机一阶模型过于简化（无齿隙、无静摩擦）
