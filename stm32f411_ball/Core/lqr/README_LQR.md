# LQR 稳球控制律（Core/lqr/）

可替代滑模 PD 的第二种稳球控制律：**LQR 状态反馈 + 积分增广**。
由 `Core/Inc/ball_ctrl.h` 中的 `BALL_USE_LQR` 宏切换（`0`=滑模 PD 默认，`1`=LQR），
两种模式共用静摩擦脱困脉冲、丢球管理、前馈与输出整形，只有核心控制律不同。

## 1. 对象模型

球在摆杆上滚动（小角度线性化）：

```
ė = v
v̇ = -(5/7)·g·sin(u) ≈ -b·u,   b = (5/7)·9810·π/180 ≈ 122.3 mm/s²/°
```

u 为摆角（°），e 为球相对目标偏差（mm），v 为球速（mm/s）。

## 2. 增益推导

### 2.1 K1/K2：双积分器 LQR 闭式最优解

代价函数 `J = ∫(Q_e·e² + Q_v·v² + R·u²)dt`，取 `Q = [625, 25]`、`R = 1`，
双积分器 LQR 有 Riccati 闭式解：

```
k1 = √Q_e / b            = 25    / 122.3 = 0.2044 °/mm
k2 = √(Q_v + 2√Q_e) / b  = √75   / 122.3 = 0.0708 °/(mm/s)
```

闭环等效二阶参数：`ωn = √(b·k1) = 5 rad/s`，`ζ = b·k2/(2ωn) = 0.866`。
对比滑模 PD（KP=0.22, KD=0.05）等效 `ζ≈0.59`，LQR 阻尼显著更优
（线性仿真无积分时超调 0.5% vs PD 10.6%）。

### 2.2 KI：低权重积分增广

积分项 `u_i = ki·∫e dt` 消除常驻机械偏差（杆不水平、静摩擦偏置），
**替代滑模模式的"回零偏学习"**（LQR 模式下自动关闭偏置学习）。

`ki = 0.06 °/(mm·s)`，Routh 裕度 24，条件积分抗饱和（±8° 输出限幅）。

### 2.3 为什么不用 3 状态完整 LQI？

把积分状态增广进 LQR（LQI）求解过 Q/R 网格 500+ 组（R∈[1,30000]，
q_i∈[1,250]），结论是本对象上存在**结构性权衡**：

| Q/R 方向 | 结果 |
|---|---|
| R 小（积分权限大） | 增益爆炸：k1 达 1.3~28 °/mm，全程限幅饱和，等效乒乓控制 |
| R 大（增益压回量级） | 积分通道拉低主阻尼：ζ<0.6，50mm 阶跃超调 50% |

即"LQR 最优"的数学解在本对象上不是工程可用的解。故采用工程标准做法：
**2 态 LQR 最优解 + 低权重外部积分**（等效于 q_i→0⁺ 极限的 LQI）。
Kleinman 迭代数值解已用 CARE 残差（~1e-13）交叉验证，求解脚本见
`lqr_compare.py / lqr_diag.py / lqr_scan_x.py / lqr_scan_r2.py`（工作目录存档）。

## 3. 仿真验证（按固件离散行为：原始误差 + 0.5mm 死区 + 条件积分，Euler）

| 场景 | dt=10ms | dt=20ms（视觉帧驱动，实际工况） | 滑模 PD 对照 |
|---|---|---|---|
| e0=50mm 超调 | 9.4% | 9.3% | 10.6% |
| e0=50mm 整定(\|e\|<2mm) | 3.7s | 3.6s | 1.0s |
| 0.5° 坡度偏差稳态差 | 0.65mm | 0.65mm | 2.44mm（无积分消不掉） |
| 1.0° 坡度偏差稳态差 | 1.30mm | 1.29mm | 4.88mm |

说明：
- LQR 整定时间略长（阻尼更高、少过冲换来的），但**偏差抑制是质变**：
  车行驶中坡度/摩擦引起的常驻偏差从 ~2.4mm 降到 ~0.7mm。
- 无偏差驻留点在中心死区边缘（±0.6mm 内），死区+积分冻结的固有行为，
  与滑模 PD 模式同级，远小于赛题精度要求。

## 4. 定点实现

全整数运算（Cortex-M4 无浮点单元压力）：

| 项 | 公式（mdeg） | 宏 |
|---|---|---|
| P | `2044 × err01 / 100` | `BALL_LQR_KP_NUM` |
| D | `708 × v / 10` | `BALL_LQR_KD_NUM` |
| I | `6 × s_i_acc / 1000` | `BALL_LQR_KI_NUM` |

- `err01`：球偏差 0.1mm；`v`：球速 mm/s；`s_i_acc`：积分累加器（0.1mm·ms，
  = err01×dt_ms 累加，按实测帧间隔折算，帧率波动不影响积分精度）
- 条件积分：输出贴限幅或误差为 0（中心死区）时冻结，防饱和防驻留抖动
- `ball_lqr_reset()`：启动/重捕获/丢球回平时清积分（ball_ctrl.c 调用）

## 5. 切换与整定

**切换**：`Core/Inc/ball_ctrl.h` 中 `#define BALL_USE_LQR 1` → 全量重编译。
两模式不可运行时切换（编译期选择），比赛现场建议提前把两个固件都编好。

**整定顺序**（改 `Core/lqr/ball_lqr.h`）：

| 现象 | 动作 |
|---|---|
| 回中偏慢 | 加 `BALL_LQR_KP_NUM`（每 +200 约提 ωn 3%） |
| 过冲/来回振 | 加 `BALL_LQR_KD_NUM` 或减 `KP` |
| 稳态差消得慢 | 加 `BALL_LQR_KI_NUM`（步进 2，>10 注意超调） |
| 积分 windup 型过冲 | 减 `BALL_LQR_KI_MAX_MDEG`（默认 8000 = ±8°） |

**与滑模 PD 的取舍**：
- LQR：线性区行为可预测（有模型与最优性依据）、抗常驻偏差强；
  依赖模型参数 b（球-杆摩擦系数偏离 5/7 理论值时按实测整定 KP/KD 比例）。
- 滑模 PD：参数物理意义直白、久经台架验证；无积分、依赖偏置学习。

建议：台架先用 LQR 跑 50mm 阶跃对比两者超调与整定时间，车联调时重点看
A 帧前馈叠加后是否有共振（LQR 阻尼高，理论上更耐受前馈扰动）。
